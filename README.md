# Python Projects

This repository contains beginner Python projects created while learning Python programming.

## Projects

### Calculator
- Performs basic arithmetic operations.
- Uses functions and user input.

### Number Guessing Game
- Interactive guessing game using the random module.
- Includes input validation and multiple attempts.

### Password Generator
- Generates secure random passwords.
- Allows customizable password length.

### Caesar Cipher
- Encrypts and decrypts text using the Caesar Cipher algorithm.
